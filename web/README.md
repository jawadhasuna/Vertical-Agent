# Vertical Agent

**Live app:** https://verticalagent.vercel.app

Vertical Agent is a RAG-powered Q&A chatbot that answers questions about humanoid robots — Atlas, Optimus, Figure01, ASIMO, Ameca, and Unitree H1 — grounded strictly in ingested source documents. It combines Chroma Cloud for vector search, Google Gemini for embeddings and chat, and a Next.js frontend with an on-topic guardrail that declines unrelated questions before they ever reach the model.
